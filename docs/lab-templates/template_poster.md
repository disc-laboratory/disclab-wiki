# DISCLab Slides Template

This page provides the official poster template used in the DISC Laboratory for research sharing.

## Description

The poster template is designed to ensure a consistent and professional visual identity across all research presentation from the lab. It is suitable for:

- conference presentations;
- internal group meetings;
- other required events;

The template follows a clean structure aligned with NTU and DISC Lab branding.

## Files

- [Download the LaTeX poster template](files/DISCLab_Poster_template.tex)
- [Download the PDF example](files/DISCLab_Poster_template.pdf)

## Usage

- Use this template as a starting point for all poster presentations;
- Create a copy before editing;
- Keep the overall structure and style consistent;
- Adapt content (figures, sections, examples) to your specific presentation.

## Notes

- Ensure all figures are high quality and readable;
- Avoid overcrowded — prioritize clarity;
- Maintain consistent formatting across sections;
- Use the template to reinforce a coherent lab identity.
- Ensure all referenced images, logos, or folders used in the `.tex` file are available locally before compiling.
- Add/organize dedicated directories (e.g., `figures/`; `brand\`; `videos\`);
- Compile using a LaTeX workflow.
